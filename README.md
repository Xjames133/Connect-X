This is a Connect 4 project I made my sophomore year of college in my Software Development class. The Idea is that it's connect 4 but you can choose how many to win (Connect X) and choose how many people can play. 

This repository also includes all of the diagrams and documentation we needed to create in order to complete the project. This includes the amount of ways of winning a game, how placing chips works, how to check those wins and making sure the boundaries were proper.
